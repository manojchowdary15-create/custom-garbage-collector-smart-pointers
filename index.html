🛡️ SmartPointer<T> & RAII

Implements standard C++ Reference Counting with a shared ControlBlock<T>. Increments on copy, decrements on destruction.

template <typename T> class SmartPointer { T* ptr; ControlBlock<T>* controlBlock; // Automatic RAII increment/decrement };

⚠️ The Circular Reference Problem

When Node A points to Node B and Node B points to Node A, both have referenceCount = 1 even after all stack root pointers are destroyed! Pure reference counting fails to free this cycle.

rootA->next = rootB; rootB->next = rootA; root_pointers.clear(); // Leak! RC still 1

🧹 Mark-and-Sweep Garbage Collection

The GarbageCollector solves the circular leak:

  • Mark Phase: Traces all reachable nodes starting from the Root Set (stack/global pointers).
  • Sweep Phase: Traverses the entire heap. Any object with marked == false is unreachable garbage and is safely destroyed, reclaiming memory regardless of circular refCounts!
